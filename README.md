# Auto-Scaler

Auto scaling based on load

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Auto-Scaler.git
cd Auto-Scaler
go build -o auto-scaler .
```

## Usage

```bash
.auto-scaler .
.auto-scaler --path ./src
```
